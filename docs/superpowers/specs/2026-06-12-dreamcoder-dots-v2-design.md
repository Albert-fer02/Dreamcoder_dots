# Dreamcoder Workbench v2.0 — Design Spec

**Date:** 2026-06-12
**Author:** Dreamcoder + AI Assistant
**Status:** Approved (pending spec review)

## Goal

Transform Dreamcoder Workbench from an Arch-focused dotfiles project into a **full OS experience** that matches or exceeds ML4W and Gentleman.Dots, while maintaining the unique Dreamcoder design system (token-based themes, health-first, day/night automation).

## Scope

Five major deliverables:

1. **New Terminal Configs** — Tmux, Zellij, Nushell, WezTerm, Alacritty with Dreamcoder themes
2. **Go Binary Installer** — Multi-platform TUI installer with Homebrew tap
3. **Vim Mastery Trainer** — RPG-style interactive Vim learning module
4. **AI Development Layer** — Separate repo (like gentle-ai) for AI tool configs
5. **Documentation** — Full docs with migration guides and onboarding

### 2.5 Build System

```makefile
BINARY_NAME := dreamcoder-dots
VERSION := $(shell git describe --tags --always --dirty)
LDFLAGS := -ldflags "-X main.Version=$(VERSION)"

PLATFORMS := linux/amd64 linux/arm64 darwin/amd64 darwin/arm64

build-all:
 @for platform in $(PLATFORMS); do \
  OS=$${platform%/*}; \
  ARCH=$${platform#*/}; \
  echo "Building $$OS/$$ARCH..."; \
  GOOS=$$OS GOARCH=$$ARCH go build $(LDFLAGS) -o $(BINARY_NAME)-$$OS-$$ARCH; \
 done

release: build-all
 gh release create $(VERSION) $(BINARY_NAME)-* --title "v$(VERSION)"
```

## 3. Vim Mastery Trainer

### 3.1 Module Structure

| #   | Module              | Keys                | Lessons | Boss Fight         |
| --- | ------------------- | ------------------- | ------- | ------------------ |
| 1   | Horizontal Movement | `w e b f t 0 $ ^`   | 15      | Navigate code maze |
| 2   | Vertical Movement   | `j k G gg { }`      | 15      | Jump to targets    |
| 3   | Text Objects        | `iw aw i" a( it at` | 15      | Select & transform |
| 4   | Change & Repeat     | `d c dd cc D C x`   | 15      | Refactor challenge |
| 5   | Substitution        | `r R s S ~ gu gU J` | 15      | Text alchemy       |
| 6   | Macros & Registers  | `qa @a @@ "ay "+p`  | 15      | Automation master  |
| 7   | Regex Search        | `/ ? n N * # \v`    | 15      | Find the pattern   |

### 3.2 RPG System

**XP Rewards:**

- Lesson complete: +10 XP
- Boss fight complete: +50 XP
- Perfect score (no hints): +25 XP bonus
- Speed bonus (< 30s): +15 XP

**Levels:**

| Level | XP Required | Title          |
| ----- | ----------- | -------------- |
| 1     | 0           | Vim Beginner   |
| 2     | 100         | Vim Apprentice |
| 3     | 300         | Vim Journeyman |
| 4     | 600         | Vim Expert     |
| 5     | 1000        | Vim Master     |
| 6     | 1500        | Vim Wizard     |
| 7     | 2500        | Vim Sage       |

**Achievements:**

- 🏆 "First Steps" — Complete first lesson
- ⚡ "Speed Demon" — Complete lesson in < 15s
- 🎯 "Perfect Score" — Complete lesson without hints
- 🔥 "On Fire" — 5 lessons in a row without mistakes
- 🧙 "Vim Wizard" — Reach level 6
- 🎪 "Regex Master" — Complete all regex lessons
- 💀 "Boss Slayer" — Complete all boss fights

## Success Criteria

1. **All 5 terminal configs** (Tmux, Zellij, Nushell, WezTerm, Alacritty) work with `dreamcoder sync`
2. **Go binary** compiles for all 4 platforms (linux/amd64, linux/arm64, darwin/amd64, darwin/arm64)
3. **Homebrew install** works: `brew install dreamcoder08/tap/dreamcoder-dots`
4. **TUI installer** launches and navigates through all screens
5. **Vim Trainer** has at least module 1 complete with XP system
6. **AI layer** installs independently via separate repo
7. **Documentation** covers all platforms with working examples
8. **All existing tests pass** — no regressions

## Out of Scope

- Hyprland/Waybar/Rofi config (already partially exists, separate effort)
- Nix migration (future bleeding-edge branch)
- Windows native support (WSL only)
- iOS/iPadOS

## Risks

| Risk                  | Mitigation                             |
| --------------------- | -------------------------------------- |
| Go binary size bloat  | Use UPX compression, strip debug info  |
| TUI complexity        | Start with Bubbletea, proven framework |
| Theme engine changes  | Add renderers incrementally, test each |
| Cross-platform compat | CI matrix build + Docker testing       |
| Vim trainer scope     | Ship module 1 first, iterate           |

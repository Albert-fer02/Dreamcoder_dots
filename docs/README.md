## Getting Started

### Install via Homebrew (Recommended)

```bash
brew install dreamcoder08/tap/dreamcoder-dots
dreamcoder-dots
```

### Install via Curl

```bash
curl -fsSL https://raw.githubusercontent.com/dreamcoder08/dreamcoder-dots/main/install.sh | bash
```
